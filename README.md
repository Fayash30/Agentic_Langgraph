# 🤖 Agentic AI with LangGraph

A hands-on implementation repository exploring **Agentic AI development using LangGraph and LangChain**.

This repository focuses on building LLM-powered applications, understanding graph-based workflows, and exploring human involvement in AI decision-making.

## 📚 Modules

### 1. Basic Chatbot
- Building a conversational AI application.
- Integrating LLMs with LangGraph.
- Understanding the fundamentals of graph-based execution.
- Working with conversational interactions.

### 2. Human Assistance
- Exploring human involvement in AI workflows.
- Understanding how human input can complement AI execution.
- Building workflows that incorporate human assistance.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Core development |
| LangGraph | Agent orchestration and graph workflows |
| LangChain | LLM application framework |
| Google Gemini | LLM integration |
| Groq | LLM inference |
| OpenAI | LLM integration |
| Tavily | Web search integration |
| UV | Dependency management |

## 🧠 Core Concepts

- **LLM Integration:** Connecting language models to AI applications.
- **Graph-Based Workflows:** Structuring AI execution using LangGraph.
- **Conversational AI:** Building applications that interact with users.
- **Human Assistance:** Incorporating human input into AI workflows.
- **Agent Orchestration:** Exploring how LLM-powered components work together.

- Understand LangGraph fundamentals.
- Build graph-based LLM applications.

- Explore human-assisted AI workflows.
